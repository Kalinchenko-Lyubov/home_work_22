# Интернет-магазин

Учебный проект на Django, разработанный в рамках курса SkyPro.  
Проект представляет собой простой интернет-магазин с главной страницей и страницей контактов.

---

## Описание проекта

Проект позволяет:

- отображать главную страницу интернет-магазина;
- отображать страницу с контактной информацией;
- отправлять форму обратной связи;
- обрабатывать POST-запросы;
- выводить данные формы в консоль сервера;
- использовать Bootstrap для стилизации страниц.

---

## Реализованный функционал

### Главная страница

- вывод информации о сервисе;
- Bootstrap-карточки;
- навигационное меню.

### Страница контактов

- контактная информация;
- форма обратной связи;
- обработка POST-запросов;
- вывод данных формы в консоль.

---

## Маршрутизация

В проекте реализованы следующие URL-адреса:

| URL | Страница |
|---|---|
| `/` | Главная страница |
| `/contacts/` | Контакты |

Для подключения маршрутов приложения используется `include()`.

## Как запустить проект

### 1. Клонировать репозиторий

    git clone https://github.com/Kalinchenko-Lyubov/home_work_22.git

### 2. Перейти в папку проекта

### 3. Установить зависимости

poetry install

### 4. Активировать виртуальное окружение

poetry shell

### 5. Запустить сервер

    python manage.py runserver

После запуска проект будет доступен по адресу:

    http://127.0.0.1:8000/

---

На странице контактов реализована форма обратной связи.

После отправки формы:

- Django принимает POST-запрос;
- данные формы обрабатываются во view;
- данные выводятся в консоль сервера;
- пользователю отображается сообщение об успешной отправке.
